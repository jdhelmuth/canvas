# Canvas 1.0.3 (65)

## Changes

- Keep the current photo visible when rotating an iPad while Canvas prepares a different portrait-photo grouping.
- Preserve playback progress, pause state, and navigation history through regrouping, and wait for the new group before advancing.
- Prevent stale image loads or removed provider assets from restoring an outdated companion photo.
- Complete pending image reloads after scheduled playback resumes, including a library refresh or rotation during recovery.
