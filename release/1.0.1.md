# Canvas Slideshow 1.0.1 (63)

## What's new

- More dependable unattended slideshows, including recovery from unavailable photos.
- Safer Google-to-Apple album mirroring and fresher photo caches.
- Clearer weather freshness; a connected Ambient station supplies the only weather conditions, with Apple Weather used when no station is connected.
- Faster navigation for large photo collections and reduced imported-image memory use.
- More reliable audio playback, imports, date filters, and settings recovery.

## PWS correction for build 63

- A saved station takes precedence over an older Apple Weather preference; disconnecting the station restores Apple Weather.
- Ambient no longer fetches Apple Weather. The overlay shows only station conditions, station measurements, and optional independently sourced AirNow AQI. Legacy cached local forecasts cannot produce a second conditions block or Apple attribution.
- Missing sky descriptions use a thermometer instead of a misleading cloud. The secondary temperature is explicitly labeled “Feels like.”
- Targeted validation passed weather tests and both PWS-only and Apple-only UI checks. The live simulator preview confirmed the corrected display. An obsolete weather-enrichment helper and its two tests were removed. The permission unit test now has isolated Apple-only settings; the landscape test waits for rotation instead of skipping when the window has not rotated yet. A simulator restart resolved a stuck orientation, after which the landscape check passed.
